# Arthur · Care Well — v1.4 (single-player)

This is a full GitHub Pages root replacement, based on v1.3. Replace all repository root files and the `assets` directory. No build step or external service is required.

## Changes
- New, distinct illustrated views for **Legible Campus** (recognizable wayfinding and landmarks) and **Human Welcome** (an actual guide helping Arthur). Digital Arrival stays untouched.
- Investment Impact is shorter: one benefit, one operational burden, one essential **key design/operations decision**, and one resource opportunity-cost statement.
- The registration implications are present directly in Digital Arrival and Human Welcome; selecting centralized, departmental, or federated registration remains a later game decision.
- More detail (resource math, opening/future phases, design guardrails, and Design Moment links) is available in an optional expansion.
- Preserves ACHC/Arthur intro, four-stop baseline, How to Play, persistent game map, three Decision → Impact → Reveal cycles, opening-day priority, external-provider challenge, Design Moments, Design & Operations Lens, final results.
- Uses a v1.4-specific local saved game key.

## Suggested QA
Play one portfolio containing each of Digital Arrival, Legible Campus, and Human Welcome; inspect their images on a phone and desktop. Also complete the full single-player flow through final results and test returning to an earlier investment.
