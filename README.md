# Arthur · Care Well v1.3 — Single player

A ready-to-upload GitHub Pages replacement; no npm/build step required.

## Changes from v1.2
- Persistent seven-chapter progress map (ACHC & Arthur, Baseline, Learn, Investments, Opening, Change, Design).
- New **How to Play** screen immediately after the four-stop baseline, explaining the three investment cards, their resource limits, the impact/reveal rhythm, opening-day readiness, and the Design & Operations close.
- New illustrated bridge: **Let’s see how we can make Arthur’s journey successful**, before investment one.
- New dedicated laboratory visual for the baseline lab stop, replacing the broad patient-journey collage.
- New Department Network corridor/wayfinding visual, replacing the broad journey collage on its decision, impact and reveal cards. Digital Arrival imagery is unchanged.
- How to Play available from the persistent header; prior game state is preserved when returning to play.
- Separate v1.3 saved-game key; previous versions are unaffected. New players always start at the introduction.

No changes to budgets, investment options, outcome math or the six two-screen Design Moments.

## Deployment
Upload the **contents** of this archive to the GitHub repository root, including the `assets/` folder and `.nojekyll`. Commit and hard refresh. The header should display `care-well-sp-1.3.0`.

## Scenario note
ACHC/Arthur is an illustrative design visioning simulation. Patient procedure requirements and the proposed care pathways are educational assumptions rather than an approved care model.
