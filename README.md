# Arthur · Care Well v1.9 — Consequences & Character Continuity Preparation

Complete single-player GitHub Pages replacement. Copy **all** files, including `asset-bundle.js` and `assets/`, to the repository root. The version in the top bar should read `care-well-sp-1.9.0`. A new saved-game key is used (`arthur-care-well-v19`).

## What changed

- **Real trade-off reveal:** When a later investment uses the last resources that previously made an earlier watershed operating model affordable, a short, dedicated Arthur-centred consequence screen appears between Investment Impact and Arthur Reveal. The investment retains positive value. The previously affordable operating model is flagged as phased, not worthless.
- **No premature promises:** The Design Shift now says "Affordable now, if prioritized" and cautions that later investments can change feasibility. Opening-day readiness is confirmed after all three investments.
- **Day-one versus future:** The opening-day screen visibly distinguishes design enablement from funded operating-model activation.
- **Reserve trust:** A response reserve is offered only when there is an operational or partner-handoff result it can improve. It costs 1 Change and 1 Operations when activated, and cannot create new clinical capacity. No resources are deducted for a reserve that will not help.
- **Visual stability:** The embedded watershed and Design Shift assets remain bundled. Original decision cards, six Design Moments and the current Arthur story are preserved.
- **Character continuity:** This release deliberately does not generate a different face for Arthur. The original reference images from the user's local OneDrive folder were not accessible. Once those are uploaded, replace the inconsistent character-containing assets with images based on a confirmed single reference.
